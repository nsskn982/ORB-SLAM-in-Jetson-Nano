\chapter{Functions}

\section{API Documentation}

\subsection{CameraModule::captureFrame()}
Acquires a single frame from camera and returns as cv::Mat.
\begin{itemize}
    \item Returns: BGR image, 640x480 resolution
    \item Throws: CameraException on timeout
\end{itemize}

\subsection{FeatureExtractor::extractKeypoints()}
Extracts and describes features from image.
\begin{itemize}
    \item Parameters: image (cv::Mat), algorithm (string: \texttt{SIFT}/\texttt{ORB})
    \item Returns: std::vector<KeyPoint>, cv::Mat descriptors
\end{itemize}

\subsection{OdometryEstimator::computeTransform()}
Estimates rigid transformation between consecutive frames.
\begin{itemize}
    \item Parameters: prev\_descriptors, curr\_descriptors, matches
    \item Returns: cv::Mat transformation matrix (4x4)
\end{itemize}

\subsection{SLAMBackend::optimizePoseGraph()}
Performs pose graph optimization using g2o.
\begin{itemize}
    \item Parameters: pose\_graph, constraints
    \item Returns: optimized poses, final error
\end{itemize}

\section{Thread Management}

Main threads:
\begin{itemize}
    \item Camera capture thread (real-time priority)
    \item Feature extraction thread
    \item Pose estimation thread
    \item Optimization thread (lower priority)
\end{itemize}
