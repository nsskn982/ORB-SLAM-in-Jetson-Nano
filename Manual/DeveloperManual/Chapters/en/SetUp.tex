\section{SparkFun Jetbot Hardware Assembly}

\subsection{Component Verification Before Assembly}
\begin{itemize}
    \item \textbf{Jetson Nano Developer Kit V2}: Verify "v2" marking on board silkscreen
    \item \textbf{SparkFun Chassis}: JetBot robot platform (SKU ROB-16417 or newer)
    \item \textbf{DC Motors}: 2x TT-motors pre-installed in chassis (3-6V rated)
    \item \textbf{Quadrature Encoders}: 2x encoders at motor shafts (48 PPR standard)
    \item \textbf{USB Camera}: Standard webcam with UVC compatibility (640x480 typical)
    \item \textbf{Power Distribution}: 4xAA battery holder or 5V/3A USB-C adapter minimum
\end{itemize}

\subsection{Motor Driver H-Bridge Configuration}

Required motor control electronics:

\begin{itemize}
    \item \textbf{Driver IC}: L298N or DRV8833 dual-channel motor driver recommended
    \item \textbf{Input Logic Voltage}: 3.3V signals from Jetson GPIO
    \item \textbf{Motor Supply Voltage}: 5V rail separate from Jetson power
    \item \textbf{Ground Reference}: Common ground between Jetson and motor driver
    \item \textbf{PWM Frequency}: 20 kHz (minimize switching losses and acoustic noise)
    \item \textbf{Dead Time}: Insert 1-2 microseconds between phase transitions
    \item \textbf{Current Limiting}: Per-motor limit approximately 500mA
\end{itemize}

\section{Jetson Nano Development Environment Setup}

\subsection{Operating System Foundation}

\begin{itemize}
    \item JetPack 4.6.1 or newer with Ubuntu 18.04 LTS or 20.04 LTS (Arm64)
    \item Prepare 2GB minimum free disk space for development tools
    \item Execute system updates: \texttt{sudo apt-get update \&\& sudo apt-get upgrade -y}
\end{itemize}

\subsection{Build Tools and Compilers}

Essential packages for compiling SparkFun Jetbot software:

\begin{itemize}
    \item \textbf{Build Foundation}: GCC 7+ with ARMv8 architecture support
    \item \textbf{Build System}: CMake 3.10+, Make, autotools
    \item \textbf{Version Control}: Git with full functionality
    \item \textbf{Python}: Python 3.6+ with pip, numpy, opencv-python
\end{itemize}

\subsection{Critical Libraries for SparkFun Jetbot}

\begin{description}
    \item[OpenCV 3.3+] Pre-compiled for Jetson available via \texttt{sudo apt install libopencv-dev}
    \item[g2o Optimizer] Pose graph SLAM backend (compile from source, 15-20 minutes on Jetson)
    \item[Eigen 3.x] Linear algebra library (dependency of g2o)
    \item[ROS Melodic/Noetic] Full desktop environment with catkin build tools
    \item[CUDA 10.2] GPU acceleration toolkit (pre-installed on JetPack)
    \item[cuDNN] Neural network library (optional, for deep learning)
\end{description}

\subsection{Building on Jetson Nano Hardware Constraints}

Memory and thermal considerations:

\begin{itemize}
    \item \textbf{Parallel Build Jobs}: Use \texttt{make -j2} ONLY (Jetson has 4GB RAM)
    \item \textbf{SIMD Optimization}: Enable with \texttt{-march=armv8-a -mfpu=neon}
    \item \textbf{CUDA GPU Targeting}: Set \texttt{-DCUDA\_ARCH\_BIN=5.2} for Maxwell GPU
    \item \textbf{Alternative Strategy}: Cross-compile on x86 workstation for faster builds
    \item \textbf{Thermal Management}: Monitor CPU temperature during compilation
\end{itemize}

\section{Encoder and Motor Hardware Interface}

\subsection{Quadrature Encoder Reading Specifications}

\begin{itemize}
    \item \textbf{Resolution}: 48 increments per complete wheel rotation (\textsuperscript{o} per tick)
    \item \textbf{Phase Logic}: Channel A leads Channel B during forward motion
    \item \textbf{Maximum Frequency}: 2.56 kHz per encoder at rated motor RPM
    \item \textbf{Reading Implementation}: GPIO sysfs poller or kernel interrupt handler
    \item \textbf{Synchronization}: Timestamp all encoder reads with frame captures
\end{itemize}

\subsection{PWM Motor Control Output}

\begin{itemize}
    \item \textbf{GPIO Pins}: 18 (GPIO79) for left motor, 32 (GPIO80) for right motor
    \item \textbf{Frequency}: 20 kHz via \texttt{/sys/class/pwm/pwmchip0}
    \item \textbf{Duty Cycle}: 0-100\% represented as 0-100000 in sysfs
    \item \textbf{Ramp Rate}: Avoid abrupt transitions (limit to 100\% per second maximum)
    \item \textbf{Direction Control}: Separate GPIO pairs for motor polarity selection
\end{itemize}
