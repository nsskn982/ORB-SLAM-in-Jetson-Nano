\chapter{Folder Structure}

\section{Repository Overview}

The repository is divided into directories for hardware documentation, software, Jetson Nano development, manuals, references, thesis material, presentations, and project management.

\section{Top-Level Structure}

\begin{verbatim}
	250901-Jetson-Nano-Ground/
	|-- README.md
	|-- author.xlsx
	|-- Assembly/
	|-- Code/
	|-- JetsonNano/
	|-- Manual/
	|-- MLbib/
	|-- Thesis/
	|-- Presentations/
	|-- Poster/
	`-- ProjectManagement/
\end{verbatim}

\section{Assembly Directory}

\subsection{Purpose}

The \texttt{Assembly/} directory contains hardware documentation, assembly instructions, and related \LaTeX{} files.

\section{Code Directory}

\subsection{Purpose}

The \texttt{Code/} directory contains the main software implementations, microcontroller programs, and CAD-related files.

\subsection{Structure}

\begin{verbatim}
	Code/
	|-- JetBot/              # Robot control software
	|-- DomainSystem/        # Domain-specific modules
	|-- MicroPython/         # MicroPython programs
	`-- Solidworks/          # CAD models and G-code files
\end{verbatim}

\subsection{JetBot}

\begin{verbatim}
	Code/JetBot/
	|-- CMakeLists.txt
	|-- package.xml
	|-- README.md
	|-- requirements.txt
	|-- run_jetbot_all.sh
	|-- config/              # YAML configuration files
	|-- launch/              # ROS2 launch files
	|-- models/              # Trained ML models
	|-- scripts/             # Python and shell scripts
	`-- src/                 # Optional C++ source files
\end{verbatim}

\subsection{Solidworks}

\begin{verbatim}
	Code/Solidworks/
	|-- RobotBumper.SLDPRT
	|-- RobotBumper.3mf
	|-- RobotBumper2.SLDPRT
	|-- RobotBumper2.3mf
	|-- RobotBumper_0.2mm_PLA_MK3_45m.gcode
	`-- RobotBumper2_0.25n_0.1mm_ABS_MK3S_3h13m.gcode
\end{verbatim}

\section{JetsonNano Directory}

\subsection{Purpose}

The \texttt{JetsonNano/} directory contains Jetson Nano-specific code, system configuration, datasets, images, and experimental results.

\subsection{Structure}

\begin{verbatim}
	JetsonNano/
	|-- Code/
	|   |-- JetsonNano/          # Localization and avoidance code
	|   |-- Arduino/             # Arduino integration
	|   |-- TensorFlowLite/      # TFLite inference scripts
	|   `-- Nano33BLESense/      # Sensor support
	|-- System/                  # Setup and system configuration
	|-- Contents/                # Datasets, calibration data, logs
	|-- Images/                  # Captured images and results
	|-- General/                 # Documentation
	`-- tikz/                    # TikZ diagrams
\end{verbatim}
